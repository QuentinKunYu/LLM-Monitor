Recommendation Probability by Visibility

              
Algorithm: group binary rows by visibility_group, then compute mean(rec). This is the observed recommendation probability for high-visibility vs niche brands.

              

            

            

              
Model Differences

              
Algorithm: for each model, compute bias_gap = P(rec | high_visibility) - P(rec | niche). Larger gaps mean stronger high-visibility bias.

              

            

          


          
Category Heterogeneity: Strongest Popularity Bias

          
Algorithm: within each category, compute high_visibility_rate - niche_rate, then sort categories from largest gap to smallest.

          


          
Niche Brands Still Recommended

          
Algorithm: filter to niche brands with at least one recommendation, then rank by recommendation_rate = total_mentions / total_opportunities.

          


          
Visibility x Model Interaction

          
Algorithm: logit model rec ~ sub_category + model_id * visibility_group. First row is the reference model, Claude Opus 4.7; the other rows test whether each model differs from that reference.

          


          
Logistic Regression Table

          
Algorithm: baseline RQ1 logit model rec ~ model_id + sub_category + visibility_group. The high-visibility odds ratio estimates popularity bias after model and category fixed effects.

          


          
Category x Visibility Rates

          
Algorithm: group rows by sub_category x visibility_group, then report mean(rec), mentions, and total observations.
